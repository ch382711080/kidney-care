# 产品范围

## 定位

肾友档案是一个通过微信内置浏览器打开的个人健康档案 H5，帮助 IgA 肾病患者长期记录检查、用药和日常数据，复诊时快速整理资料。

第一阶段先做**单用户、纯本地、可备份恢复**的版本；不接云、不做登录、不做多用户。

## 目标用户

- IgA 肾病患者。
- 需要长期记录检查结果、用药和血压体重的慢性肾病患者。
- 希望复诊前快速回顾历史资料的患者。

## 第一阶段范围

| 模块 | 内容 |
|---|---|
| 首页 | 健康摘要、最近检查、下次复查、快捷记录、备份提醒 |
| 检查记录 | 8 大类指标；常用指标优先；同日多次；单位与参考范围按次保存；编辑、软删除、修改历史 |
| 趋势分析 | 血肌酐、eGFR、24h 尿蛋白、UACR、UPCR、尿酸、血白蛋白、血压、体重；时间筛选；单位隔离；缺失不补 |
| 用药管理 | 当前用药、历史方案；调整剂量生成新记录；停药只填结束日期 |
| 日常记录 | 血压、心率、体重、水肿、尿液外观、备注 |
| 复查计划 | 日期、项目、医院、备注、完成状态；仅页面内提醒 |
| 肾穿刺 | Lee 分级、MEST-C、病理备注；允许未报告/未知；报告图片延后 |
| 我的档案 | 基本资料、健康管理入口、备份中心、隐私说明、关于 |
| 备份恢复 | JSON 导出/导入；格式与完整性校验；合并/覆盖；导入前快照；最近备份时间与提醒 |
| 隐私 | 本地存储说明、丢失风险、最小化收集、免责声明 |

## 明确不做

- 不做自动诊断、分级、治疗建议或药物剂量建议。
- 不把健康数据写入 URL、普通日志、第三方统计或外部服务。
- 不做报告图片/PDF 上传（后续单独设计附件存储与 ZIP 导出）。
- 不做 PDF/Excel 导出、推送通知、微信登录、云同步、多用户。
- 不承诺微信清理缓存后数据仍在。
- 第一阶段不购买域名、服务器或付费云服务；不验收微信分享链接（未部署托管）。

## 产品原则

1. **记录优先**：先让用户低成本地把数据记下来，再谈分析和导出。
2. **不制造恐慌**：检验值不使用红色渲染，不自动判断“好转/恶化”，只展示数值与参考范围关系。
3. **不伪造**：没有数据就显示空状态；演示数据必须独立、明确标注，不能混入真实档案。
4. **可带走**：数据必须能导出为通用 JSON，换设备可恢复。
5. **可替换**：本地数据层通过接口隔离，未来可接云端而不重写页面。
