覆盖范围：

- 化验值解析：数值、不等式（`<`、`≤`、`>`、`≥`、全角符号）、定性文本、上下箭头。
- 参考范围标记：高 / 低 / 正常 / 未知；不等式不判断高低。
- 检查创建：指标归一化、类别派生、同日多次、`clientRequestId` 幂等。
- 检查编辑：同事务写入快照、`rev` 递增、指标整体替换、快照上限 20。
- 软删除 / 恢复：检查与指标级联；删除前快照；回收站 30 天清理；彻底删除。
- 首页摘要：最新非删除指标、最近检查、总数。
- 档案与设置仓储：默认值、创建、更新。
- 索引回归：无日期穿刺记录可通过 `[profileId+isDeleted]` 查到。
- 生产预览：Vant 图标字体只使用内联 woff2（构建时移除阿里 CDN 兜底），无第三方请求。

## 自动化

- `tests/unit/`：指标字典、领域服务、备份校验、趋势分组、用药版本。
- 使用 `fake-indexeddb` 测试 Dexie 事务与迁移。
- E2E 可选 Playwright；第一阶段不强制，避免下载浏览器与维护成本。

## 手工清单

### 手机

- 375 / 390 / 414 宽度无横向滚动。
- 底部安全区、输入框聚焦不缩放、键盘不遮挡主按钮。
- 首页、检查、趋势、档案四 Tab 切换正常。
- iOS 微信/Android 微信打开时，记录是否正常显示。
- 备份复制/粘贴在微信内可用；文件下载失败有明确提示。

### 桌面

- 侧边导航、内容最大宽度、三列指标卡。
- 文件下载正常。
- 表单键盘操作与焦点可见。

### 数据

- 导出后清空站点数据，再导入，记录数量与内容一致。
- 覆盖导入前自动快照；模拟失败后原数据不变。
- 清除全部数据后无残留真实记录（如选择删除快照）。
